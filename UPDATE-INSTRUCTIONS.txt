COOKIE TRACKER v3 UPDATE

1. In GitHub, open your Cookie-Tracker repository.
2. Replace these files in the repository root with the v3 copies:
   - index.html
   - app.js
   - styles.css
   - sw.js
   - README.md (optional, but recommended)
3. Keep manifest.webmanifest and the icons folder as they are.
4. Commit the changes to main. GitHub Pages will redeploy automatically.
5. After the deployment finishes, fully close Cookie Tracker and reopen it.
   If it still looks old, open the GitHub Pages URL in Safari, refresh once,
   then reopen the Home Screen app.

DATA SAFETY
- The storage key remains cookieTrackerDataV1, so this update is designed to
  keep the existing inventory, commissions, orders, sales, and brother payments.
- Keep your exported JSON backup until you have confirmed the update works.

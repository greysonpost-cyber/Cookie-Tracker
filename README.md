# Cookie Tracker

A phone-first, installable web app for cookie sales. No paid domain is required.

## Included
- $6 fixed price per cookie, no bundle deals
- Default flavors from the provided product list: Biscoff, Cookie Monster, Cinnamon Roll, Ferrero, Kinder, S'mores, Cookies & Cream, Chocolate Chunk
- Inventory tracking with on-hand, reserved, and available counts
- Quick sales
- Customer orders that reserve inventory until delivered or cancelled
- Paid/unpaid tracking
- Sales totals by flavor
- Brother-share tracking (starts at $4 per cookie and can be changed in Settings)
- Record payments made to brother and see remaining balance
- Offline-capable PWA after first load
- JSON backup/import and CSV sales export
- Data stored on the device using localStorage

## Put it online for free with GitHub Pages
1. Create a new GitHub repository, for example `cookie-tracker`.
2. Upload everything in this folder to the root of the repository.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will give you a free URL similar to `https://YOUR-USERNAME.github.io/cookie-tracker/`.

No custom domain is required.

## Install on iPhone
1. Open the GitHub Pages URL in Safari.
2. Tap the Share button.
3. Tap **Add to Home Screen**.
4. Open **Cookie Tracker** from the new Home Screen icon.

## Important data note
This version stores data locally on that browser/device. Export a backup from Settings periodically. If you later want automatic syncing between devices, a cloud database can be added without buying a domain.
